# Heritage
Funeral Planning &amp; Memorial Management Platform

**HavenCare** is a serene, dignified funeral event management and memorial planning web platform designed for funeral directors, grieving family organizers, and invited guests.
Built according to the Product Requirements Document (`PRD.md`), HavenCare streamlines complex funeral logistics, eliminates print layout errors, tracks chapel seating capacities, and provides a calming digital space during times of remembrance.
---
## 🌟 Key Features
### 1. 🛡️ Funeral Director Admin Command Portal
* **Memorial Case Management:** Create and manage funeral cases, set venue details, set chapel guest capacity limits, and auto-generate private RSVP access codes.
* **Catalog Inventory Manager:** Manage offered caskets, burial plot tiers, and pallbearer escort packages. Easily toggle items as **In Stock** or **Out of Stock**, and adjust prices.
* **RSVP & Capacity Monitor:** Live chapel seating progress bar, guest list table, door check-in toggles, and one-click **CSV export** for guest attendance rosters.
* **Order Approvals:** Review family arrangement plans, verify package itemization, and mark orders as approved by the funeral home.
### 2. 🕊️ Family Arrangement Selection Portal
* **Step-by-Step Selection Wizard:** Unhurried arrangement flow for browsing Caskets, Burial Plot Tiers, and Pallbearer Escort Services.
* **Out-of-Stock Protection:** Out-of-stock catalog items gracefully display an *"Out of Stock — Contact Director"* action button to prevent unfillable orders.
* **Transparent Package Summary:** Live package price calculation and custom notes field for special family requests (floral arrangements, music, etc.).
### 3. 📄 Automated Obituary Flyer & Program Generator
* **Structured Content Form:** Inputs for deceased details, dates, portrait photo, biography text, gallery photos, order of ceremony schedule, and family acknowledgments.
* **Word Count Guidance Indicator:** Displays real-time character/word count warnings if biography text exceeds recommended bounds for print templates.
* **Dual Luxury Print Presets:**
  * **1-Page Obituary Flyer:** Elegant champagne gold borders, portrait frame, schedule of service, and family acknowledgment.
  * **4-Page Program Booklet:** Cover Page, Life Story & Photo Gallery, Order of Ceremony, and Pallbearer List.
* **Export & Print:** High-resolution PDF downloads via `html2pdf.js` and direct browser print proofs.
